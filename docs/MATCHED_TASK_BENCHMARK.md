# RESEND-BASE000 matched-task benchmark

The builder executed candidate-side tasks only. A valid victory claim requires the same independent evaluator to run comparable tasks on current Resend and this frozen candidate. That independent comparison was not available and is not simulated.

Candidate evidence covers:

1. Product category and outcome visible in first viewport.
2. Deterministic verification request and generated result.
3. Fixture/tier operation changes without state loss.
4. Request, response, status, claim, and error details.
5. Failed webhook inspection, retry, and manual replay.
6. Homepage-to-documentation navigation.
7. Credential JSON and human-readable registry parity.
8. Revoked, suspended, expired, superseded, and not-found states.
9. Mobile-emulation core journey.
10. Keyboard, reduced-motion, and no-WebGL journey.
